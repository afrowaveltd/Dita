# Περίληψη των αλλαγών στην υπηρεσία αυτόματης μετάφρασης

## Επισκόπηση

Το έγγραφο αυτό συνοψίζει όλες τις αλλαγές που έγιναν στην υπηρεσία αυτόματης μετάφρασης Dita, συμπεριλαμβανομένου του αναπαράγοντα αρχιτεκτονικής, νέα χαρακτηριστικά, βελτιώσεις παρατηρησιμότητας, και βελτιώσεις εντοπισμού.

## Αλλαγές Αρχιτεκτονικής

### Αναπαραγωγικό σύστημα υποστήριξηςTranslationService

Η μονολιθική έχει αποσυντεθεί σε τέσσερις εξειδικευμένες υπηρεσίες που συντονίζονται από έναν ελαφρύ ενορχηστρωτή:

- ** BackendTranslationService** — Ενορχηστρωτής σωληνώσεων (επικύρωση σερβίρετε, ανάθεση σκηνής, χειρισμός σφαλμάτων)
- **CountriesTranslationService** — Country name synchronization (Αγγλικά → target language)
- **ΤοπικοποίησηTranslationService** — Λεξικό JSON συγχρονισμός (προστιθέμενα / μεταφερόμενα πλήκτρα)
- **ΤεκμήριαTranslationService** — Μετάφραση τεκμηρίωσης Markdown με παρακολούθηση σε επίπεδο μπλοκ
- **ΥπογραφήRΕκδότης** — Αναφορά προόδου σε πραγματικό χρόνο μέσω SignalR
- **TranslationRetryService** — Φάση-επίπεδο δοκιμή με τη διατήρηση των θέσεων

### Οφέλη

- ** Διαχωρισμός των ανησυχιών **: Κάθε υπηρεσία χειρίζεται έναν ενιαίο τομέα μεταφράσεων
- ** Βιωσιμότητα **: Οι μικρότερες τάξεις είναι πιο εύκολο να κατανοηθούν και να δοκιμαστούν
- ** Επέκταση **: Νέοι στόχοι μεταφράσεων μπορούν να προστεθούν μέσω της εφαρμογής διεπαφών
- ** Αξιοπιστία**: Οι ανεξάρτητες υπηρεσίες παρέχουν καλύτερη απομόνωση ελαττωμάτων

## Νέα χαρακτηριστικά

### Παρακολούθηση ζωντανής μετάφρασης

**Τοποθεσία **:

Μια νέα σελίδα admin που παρέχει προβολή σε πραγματικό χρόνο στον μεταφραστικό αγωγό:

- Εμφανίζει όλο το σήμα R περιστατικά καθώς συμβαίνουν
- Τύποι έγχρωμων κωδικοποιημένων μηνυμάτων (μπλε=ξεκινημένο, πράσινο=ολοκληρωμένο, κόκκινο=τρόμος)
- Banner κατάστασης σύνδεσης με αυτόματη επανασύνδεση
- Μετρητής μηνυμάτων και εξαγωγή σε JSON

### Ονομαστική θέση

Το σύστημα εντοπισμού υποστηρίζει πλέον τους κατονομαζόμενους κατόχους () για τη βελτίωση της γραμματικότητας σε διάφορες γλώσσες:

```csharp
// Usage in code
var message = Localizer["WelcomeMessage", new Dictionary<string, string>
{
    ["userName"] = "John",
    ["count"] = "5"
}];
// Result: "Hello John, you have 5 new messages"
```

Χαρακτηριστικά:
- Τιμές τοποθέτη που παρέχονται κατά το χρόνο εκτέλεσης ή αποθηκεύονται σε
- Αυτόματη απόκρυψη / αποκατάσταση κατά τη μετάφραση για την πρόληψη της διαφθοράς
- Αντίστροφα συμβατό με υφιστάμενους κατόχους θέσεων

### Συναισθηματική Μετάφραση

Τα αρχεία Markdown μεταφράζονται σταδιακά:

- ** Κατά γλώσσα εξοικονόμηση **: Κάθε γλώσσα στόχος αποθηκεύεται αμέσως μετά τη μετάφραση, μειώνοντας την πίεση μνήμης
- **Block-level tracking**: `.translation-meta.json` tracks translation status per block
- ** Επιλεκτική επανάληψη **: Μόνο αποτυχημένα μπλοκ μεταφράζονται εκ νέου στην επόμενη εκτέλεση
- **Metadata επιμονή **: Μεταφραστική κατάσταση επιβιώνει εφαρμογή επανεκκινεί

### Ενισχυμένη Λογική Επανάληψη

Τρία επίπεδα ανθεκτικότητας:

1. **HTTP retry** (LibreTranslateService): 5 προσπάθειες με εκθετική αντιστάθμιση (1s–5s)
2. ** Σταθερή επανάληψη ** (TranslationRetryService): 3 επιπλέον προσπάθειες με καθυστερήσεις 30s
3. **Block rery** (ΈγγραφαTranslationService): Αποτυχία προσπάθειας των τετραγώνων Markdown στην επόμενη εκτέλεση

### Αναφορά SignalR

Αναφορά προόδου σε πραγματικό χρόνο για όλες τις λειτουργίες αγωγών:

- Κάθε στάδιο δημοσιεύει εκδηλώσεις
- Η πρόοδος ανά γλώσσα δημοσιεύθηκε ως γεγονότα
- Τα γεγονότα λάθους περιλαμβάνουν λεπτομερές πλαίσιο (πηγή, κώδικας σφάλματος, μήνυμα)
- Αύξων αριθμός εγγύηση παραγγελία εντός κάθε διαδρομής

- **243/244 δοκιμές που περνούν ** (1 παραλείπονται λόγω της ταυτόχρονης πρόσβασης αρχείων στο περιβάλλον δοκιμής)

## Συμβατότητα προς τα πίσω

Όλες οι αλλαγές είναι πρόσθετες:

- Ο υπάρχων κωδικός εντοπισμού () λειτουργεί αμετάβλητος
- Η διαμόρφωση θέσης () λειτουργεί αμετάβλητη
- Η υπάρχουσα μορφή λεξικού JSON είναι αμετάβλητη
- Η υπάρχουσα δομή σήμανσης είναι αμετάβλητη
- Σήμα Τα μηνύματα R χρησιμοποιούν την ίδια μορφή

## Διαδρομή μετανάστευσης

Δεν απαιτείται μετανάστευση. Η αναπαράσταση είναι εσωτερική:

1. Παλαιά διατηρήθηκε ως αναφορά και στη συνέχεια αντικαταστάθηκε
2. Οι εγγραφές DI ενημερώθηκαν για τη χρήση νέων διεπαφών
3. Όλοι οι υπάρχοντες καταναλωτές δεν βλέπουν αλλαγές

## Βελτιώσεις Επιδόσεων

- **Μειωμένη χρήση μνήμης **: Αρχεία αποθηκευμένα ανά γλώσσα αμέσως αντί να τα κρατάς όλα στη μνήμη
- **Γρήγορο τρέχει **: Μόνο τροποποιημένα/αποτυχημένα μπλοκ Markdown μεταφράζονται εκ νέου
- ** Καλύτερη ορατότητα **: Η πρόοδος σε πραγματικό χρόνο βοηθά στη διάγνωση αργών σταδίων

## Μελλοντικές Βελτιώσεις

Προγραμματισμένες βελτιώσεις:

1. **AI εξομάλυνση των βραχυχρόνιων διακυμάνσεων ** — Ανασκόπηση μετά τη μετάφραση για φράσεις > 5 λέξεις
2. **Admin ταυτοποίηση ** — Περιορισμός σελίδα admin σε εξουσιοδοτημένους χρήστες
3. **Dictionary editor** — Web UI για τη διαχείριση των κλειδιών εντοπισμού
4. ** Στατιστικές μεταφράσεων ** — Χάρτες που δείχνουν αριθμούς μεταφράσεων και ποσοστά σφαλμάτων με την πάροδο του χρόνου
5. **Συνταγματική σύνταξη κατόχων τοποθεσιών ** — Υποστήριξη για εναλλακτικές μορφές τοποθέτων

## Επαφή

Για ερωτήσεις ή θέματα με τη μεταφραστική υπηρεσία, παρακαλούμε ανατρέξτε στη λεπτομερή τεκμηρίωση στον κατάλογο κάθε ενότητας ή επικοινωνήστε με την ομάδα ανάπτυξης.

# 自動翻訳サービスの変更の要約

## プロフィール

この文書は、アーキテクチャのリファクタリング、新機能、保守性の改善、ローカリゼーションの強化など、Dita自動翻訳サービスのすべての変更をまとめました.

## 建築変更

### Refactored BackendTranslationサービス

モノリシックは、軽量のオーケストラがコーディネートした4つの専門サービスに分解されています

- **BackendTranslationService** — パイプラインオーケストレータ(サーバーの検証、ステージの委任、エラー処理)
- **CountriesTranslationService** — 国名同期 (英語 → 対象言語)
- **LocalizationTranslationService** — JSON の辞書の同期(追加/削除されたキー)
- **DocumentsTranslationService** — ブロックレベルのトラッキングによるMarkdownドキュメントの翻訳
- **SignalRPublisher** — SignalR によるリアルタイムの進捗報告
- **TranslationRetryService** — プレースホルダーの保存でステージレベルの再試行

### メリット

- **懸念の分離**: 各サービスは単一の翻訳ドメインを処理する
- **維持**: 少人数の授業は理解しやすく、テストがしやすい
- **拡張性**: インターフェイス実装で新しい翻訳対象を追加できます
- **信頼性**:独立したサービスはよりよい欠陥の分離を提供します

## 新しい特徴

### ライブ翻訳モニター

**場所**:

翻訳パイプラインにリアルタイムの可視性を提供する新しい管理者ページ:

- すべてのSignalRイベントを表示
- 色分けされたメッセージのタイプ(blue=started、green=completed、red=error)
- 接続ステータスバナーと自動再接続
- メッセージカウンターとJSONへのエクスポート

### 名称 プレースホルダー

ローカリゼーションシステムは、異なる言語で文法を改善するためのプレースホルダ()という名前のプレースホルダをサポートしています

```csharp
// Usage in code
var message = Localizer["WelcomeMessage", new Dictionary<string, string>
{
    ["userName"] = "John",
    ["count"] = "5"
}];
// Result: "Hello John, you have 5 new messages"
```

特徴:
- 実行時に提供されるプレースホルダ値または保存
- 翻訳中の自動マスキング/修復による破損防止
- 既存の位置のプレースホルダと互換性がある後方

### 通訳翻訳

マークダウンファイルは、増分的に翻訳されます

- **言語保存**: 各ターゲット言語は、翻訳直後に保存され、メモリ圧力を削減します
- **ブロックレベルの追跡**:ブロックごとの翻訳ステータスを追跡
- **選択的な再試行**: 次の実行に失敗したブロックのみが再翻訳されます
- **メタデータ永続**: 翻訳状態はアプリケーションの再起動を生き残ります

### 強化されたリトライロジック

弾性の3つのレベル:

1. **HTTP retry** (LibreTranslateService):指数関数的なバックオフ(1s-5s)による5つの試み
2. **Stage retry** (TranslationRetryService): 30秒遅延で3件の追加試み
3. **Block retry** (DocumentsTranslationService): 失敗したMarkdownブロックは、次の実行時に取得

### SignalR レポート

すべてのパイプライン操作のためのリアルタイムの進捗報告:

- ステージごとにイベントを公開
- イベントとして公開された言語の進捗
- エラーイベントには、詳細なコンテキスト(ソース、エラーコード、メッセージ)が含まれます
- 各実行内でのシーケンス番号の保証

## 後方互換性

すべての変更は添加物です:

- 既存のローカリゼーションコード()は変更されない作業
- 位置決め()は変更されない働きます
- 既存のJSON辞書形式は変更されません
- 既存のMarkdownの構造は変更されません
- SignalR メッセージは同じフォーマットを使用します

## 移行パス

移行は必要ありません。 リファクタリングは内部です

1. 古いことは参照として保存され、それから取り替えられました
2. DI の登録は新しいインターフェイスを使用するために更新されました
3. すべての既存の消費者は変化を見ない

## パフォーマンス改善

- **減らされた記憶使用法**: すべてのメモリを保持するのではなく、言語ごとに保存されたファイル
- **駐車増分実行**: 変更/失敗したマークダウンブロックのみが再翻訳されます
- **Betterの可視性**: リアルタイムの進行は遅い段階を診断するのに役立ちます

## 未来の強化

計画された改善:

1. **AI 微調整** — フレーズのポスト・マシンの翻訳レビュー > 5 言葉
2. **管理者認証** — 管理者ページを権限のあるユーザーに制限する
3. **辞書エディタ** — ローカリゼーションキーを管理するためのWeb UI
4. **翻訳統計** — 翻訳数とエラーレートを時間とともに表示するチャート
5. **カスタムプレースホルダー構文** — 代替プレースホルダーフォーマットのサポート

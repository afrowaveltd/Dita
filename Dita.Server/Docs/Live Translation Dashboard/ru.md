# Прямая панель перевода

Live Translation Dashboard - это страница администратора, которая обеспечивает видимость автоматического перевода в режиме реального времени. Он подключается к концентратору SignalR и отображает все события трубопровода по мере их возникновения.

## URL

`/Admin/LiveTranslation`

> Note: Authentication and authorization are not yet implemented. Future versions will restrict this page to admin users only.

## Особенности

### Поток событий в реальном времени

Все события SignalR из конвейера перевода отображаются в обновленной таблице:

- ** Номер последовательности ** — Монотонный счетчик в каждом трубопроводе
- **Таймстэмп** — местное время, когда событие было получено
- **Run ID** — сокращенный GUID для корреляции
- **Stage** — значок этапа трубопровода (CheckServers, TranslateCountries и т.д.)
- ** Тип** — значок типа сообщения (StageStarted, Progress, StageCompleted и т.д.)
- **Послание** — Человеческое описание
- ** Подробности** — полная полезная нагрузка JSON данных о событии

### Статус соединения

Статусный баннер в верхней части показывает:
- **Подключение ** — установление связи SignalR
- **Связанные** — обычное получение
- ** Воссоединение** — соединение потеряно, попытка восстановить соединение
- **Disconnected** — соединение закрыто

Соединение использует автоматическое повторное соединение с экспоненциальным обратным соединением: 0s, 2s, 5s, 10s, 30s.

### Контроль

- **Clear Feed** — удаляет все отображаемые сообщения и сбрасывает счетчик
- **Export JSON** — загружает все полученные сообщения в виде файла JSON для анализа
- **Счетчик сообщений** — показывает общее количество событий, полученных в ходе этой сессии

## Сигнальный центр

Панель приборов соединяется с:

```javascript
const connection = new signalr.HubConnectionBuilder()
    .withUrl("/hubs/localization")
    .withAutomaticReconnect([0, 2000, 5000, 10000, 30000])
    .build();
```

```typescript
interface LocalizationHubMessage {
```

## Техническое осуществление

### Обратный

- **LocalizationHub** — концентратор SignalR, который передает сообщения всем подключенным клиентам
- **ISignalRPublisher** — Абстракция по хабу для использования в переводческих услугах
- **SignalRPublisher** — реализация по умолчанию, которая увеличивает монотонную последовательность и трансляцию

### Фронтенд

- Чистый HTML / JS с Bootstrap 5
- Использует клиентскую библиотеку Microsoft SignalR JavaScript (загружена с CDN)
- Нет рендеринга на стороне сервера, необходимого для подачи события

### Структура страницы

```
Dita.Server/Pages/Admin/
├── LiveTranslation.cshtml      — Razor page markup + JavaScript
└── LiveTranslation.cshtml.cs     — Page model (empty, data comes via SignalR)
```

## Будущие улучшения

## Устранение неполадок

### Dashboard показывает «Не удалось подключиться»

1. Убедитесь, что сервер работает и доступен
2. Проверьте консоль браузера на наличие CORS или сетевых ошибок
3. Подтверждается, что в
4. Убедитесь, что брандмауэр не блокирует соединения WebSocket

### События не появляются

1. Убедитесь, что URL-адрес концентратора SignalR совпадает между сервером () и клиентом ()
2. Проверьте, включен ли планировщик
3. Посмотрите журналы серверов на ошибки конвейера перевода
4. Проверьте вкладку браузера Network для сообщений WebSocket

### Сообщения вышли из строя

Поле гарантирует заказ в рамках одного пробега. Если сообщения появляются не в порядке, это может указывать:
- Перекрытие нескольких трубопроводов (не должно происходить из-за блокировки семафора)
- Проблемы с рендерингом браузера (попробуйте обновить страницу)

# Πίνακας ζωντανής μετάφρασης

Το Live Translation Dashboard είναι μια σελίδα admin που παρέχει προβολή σε πραγματικό χρόνο στον αυτόματο μεταφραστικό αγωγό. Συνδέεται με τον κόμβο SignalR και εμφανίζει όλα τα γεγονότα αγωγών καθώς συμβαίνουν.

## URL

`/Admin/LiveTranslation`

> Note: Authentication and authorization are not yet implemented. Future versions will restrict this page to admin users only.

## Χαρακτηριστικά

### Ροή γεγονότων σε πραγματικό χρόνο

Όλα τα γεγονότα SignalR από τον μεταφραστικό αγωγό εμφανίζονται σε έναν πίνακα με ζωντανή ενημέρωση:

- **Αριθμός αλληλουχίας ** — Μονοτονικός μετρητής σε κάθε διαδρομή αγωγού
- ** Χρονοσφραγίδα ** — Τοπική ώρα κατά την οποία ελήφθη το γεγονός
- ** Αναγνωριστικό διαδρομής ** — Συντόμευση GUID για συσχέτιση
- ** Σταθμοί ** — σήμα στάδιο αγωγών (Ελέγχοντες, Μεταφραστές Countries, κ.λπ.)
- **Τύπος ** — Ετικέτα τύπου μηνύματος (στάδιοStarted, Progress, StageComplete, κ.λπ.)
- **Μήνυμα ** — Ανθρώπινη αναγνώσιμη περιγραφή
- **Λεπτομέρειες ** — Πλήρες ωφέλιμο φορτίο JSON των δεδομένων γεγονότων

### Κατάσταση σύνδεσης

Ένα banner κατάστασης στην κορυφή δείχνει:
- **Σύνδεση ** — Δημιουργία σύνδεσης SignalR
- **Σύνδεση ** — Λαμβάνοντας γεγονότα κανονικά
- ** Επανασύνδεση ** — Απώλεια σύνδεσης, προσπάθεια επανασύνδεσης
- **Disconnected ** — Κλείσιμο σύνδεσης

Η σύνδεση χρησιμοποιεί αυτόματη επανασύνδεση με εκθετική αντιστροφή: 0s, 2s, 5s, 10s, 30s.

### Έλεγχοι

- ** Καθαρή ροή ** — Καταργεί όλα τα εμφανιζόμενα μηνύματα και επαναφέρει τον μετρητή
- **Export JSON** — Λήψεις όλων των ληφθέντων μηνυμάτων ως αρχείο JSON για ανάλυση
- ** Μετρητής μηνυμάτων ** — Εμφανίζει τον συνολικό αριθμό των γεγονότων που ελήφθησαν σε αυτή τη συνεδρία

## Κόμβος SignalR

Το ταμπλό συνδέεται με:

```javascript
const connection = new signalr.HubConnectionBuilder()
    .withUrl("/hubs/localization")
    .withAutomaticReconnect([0, 2000, 5000, 10000, 30000])
    .build();
```

### Σύμβαση μηνύματος

```typescript
interface LocalizationHubMessage {
    runId: string;        // Guid
    sequence: number;     // long
    type: LocalizationMessageType;
    stage: ProcessStage;
    timestampUtc: string; // ISO 8601
    isError: boolean;
    message: string;
    data: object | null;
}
```

## Τεχνική εφαρμογή

### Σύστημα υποστήριξης

- ** LocalizationHub** () — SignalR hub που μεταδίδει μηνύματα σε όλους τους συνδεδεμένους πελάτες
- **ISignalRPublisher** — Απόσπασμα από τον κόμβο για χρήση σε μεταφραστικές υπηρεσίες
- **SignalRPublisher** — Προκαθορισμένη υλοποίηση που αυξάνει μια μονοτονική ακολουθία και εκπομπές

### Γραφικό περιβάλλον

- Καθαρή HTML / JS με το στυλ Bootstrap 5
- Χρησιμοποιεί τη βιβλιοθήκη πελατών Microsoft Signar JavaScript (φορτωμένο από CDN)
- Δεν απαιτείται απόδοση από πλευράς εξυπηρετητή για την τροφοδοσία γεγονότων

### Δομή σελίδας

## Χρήση κατά την ανάπτυξη

1. Ξεκίνα την Ντίτα. Εφαρμογή εξυπηρετητή
2. Πλοηγηθείτε σε
3. Ενεργοποιήστε μια εκτέλεση μετάφρασης (είτε περιμένετε για τον προγραμματιστή ή καλέστε το API)
4. Παρακολουθήστε τα γεγονότα εμφανίζονται σε πραγματικό χρόνο
5. Χρήση του κουμπιού Εξαγωγής για τη σύλληψη ενός πλήρους ίχνους για αποσφαλμάτωση

## Μελλοντικές βελτιώσεις

Προγραμματισμένες βελτιώσεις για το ταμπλό:

- **Authentication ** — Περιορισμένη πρόσβαση στους χρήστες με το ρόλο
- ** Φιλτράρισμα ** — Γεγονότα φίλτρων ανά στάδιο, τύπο ή ID εκτέλεσης
- **Ιστορικές διαδρομές ** — Προβολή ολοκληρωμένων τρέχει από μια βάση δεδομένων ή αρχείο καταγραφής
- ** Στατιστικές ** — Χάρτες που δείχνουν αριθμούς μεταφράσεων, ποσοστά σφαλμάτων, και λανθάνουσα με την πάροδο του χρόνου
- ** Χειρωνακτικές ενεργοποιήσεις ** — Κουμπί για χειροκίνητη εκκίνηση συγκεκριμένων σταδίων αγωγών
- **Con ** — Επεξεργασία απευθείας από το ταμπλό
- **Διαχείριση γλωσσών** — Προβολή και επεξεργασία υποστηριζόμενων γλωσσών
- **Dictionary preview** — λεξικά εντοπισμού περιήγησης και αναζήτησης

## Αντιμετώπιση προβλημάτων

### Dashboard δείχνει " Αποτυχία σύνδεσης"

1. Επαλήθευση της λειτουργίας του εξυπηρετητή και της πρόσβασης
2. Έλεγχος κονσόλας περιηγητή για CORS ή σφάλματα δικτύου
3. Επιβεβαίωση παρουσίας
4. Εξασφαλίστε ότι κανένα τείχος προστασίας δεν εμποδίζει τις συνδέσεις WebSocket

### Τα γεγονότα δεν εμφανίζονται

1. Ελέγξτε ότι το URL του κόμβου SignalR ταιριάζει μεταξύ του εξυπηρετητή () και του πελάτη ()
2. Επαλήθευση του προγραμματιστή
3. Δείτε τα αρχεία καταγραφής του εξυπηρετητή για λάθη αγωγών μεταφράσεων
4. Έλεγχος καρτέλας δικτύου περιηγητή για μηνύματα WebSocket

### Τα μηνύματα είναι εκτός λειτουργίας

Το πεδίο εγγυάται την παραγγελία μέσα σε μία μόνο διαδρομή. Εάν τα μηνύματα εμφανίζονται εκτός λειτουργίας, μπορεί να αναφέρεται:
- Πολλαπλές διαδρομές αγωγών που επικαλύπτονται (δεν θα πρέπει να συμβεί λόγω της κλειδαριάς σηματοφόρου)
- Browser rendering issues (δοκιμάστε να αναζωογονήσετε τη σελίδα)

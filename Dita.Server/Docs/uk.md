# Резюме змін до служби автоматичного перекладу

## Огляд

Цей документ підбиває всі зміни, внесені до служби автоматичного перекладу Dita, включаючи архітектурну рефакторію, нові функції, підвищення спостережності та підвищення локалізації.

## Архітектурні зміни

### Refactored BackendTranslationПослуги

У чотири спеціалізовані послуги, що координують легкий оркестратор:

- **BackendTranslationService** — Фолайн-конструктор (референтна перевірка, делегація сценічних подій, обробка помилок)
- **CountriesTranslationService** — синхронізація назв країни (англійська → цільова мова)
- **LocalizationTranslationService** — синхронізація словника JSON (адресовані / вихідні ключі)
- **DocumentsTranslationService** — переклад документації з відстеженням рівня
- **SignalRPublisher** — Real-time progress reporting via SignalR
- **ТрансляціяПослуги** — Стійка птиця з збереженням резидента

### Переваги

- **Сепарація турбот**: Кожен сервіс ручить єдиний домен
- **Розвага**: Більшість класів легше зрозуміти і перевірити
- **Екстенсивність**: Нові цілі перекладу можна додати за допомогою інтерфейсу
- **Reliability**: Independent services provide better fault isolation

## Нові можливості

### Живий монітор перекладу

**Location**: `/Admin/LiveTranslation`

Нова сторінка адміністратора, яка забезпечує в режимі реального часу видимість в конвеєрі:

- Показати всі події SignalR, як вони відбуваються
- Типи кольорових повідомлень (синій=старий, зелений=повний, червоний=error)
- Статус на сервери
- Контракти та експорт повідомлень в JSON

### Одержувачі

Система локалізації тепер підтримує іменних власників () для покращення граматики на різних мовах:

```csharp
// Usage in code
var message = Localizer["WelcomeMessage", new Dictionary<string, string>
{
    ["userName"] = "John",
    ["count"] = "5"
}];
// Result: "Hello John, you have 5 new messages"
```

Особливості:
- Цінності власників, що надаються в режимі runtime або зберігаються в
- Автоматична маскування/відновлення під час перекладу для запобігання корупції
- Переадреса сумісна з існуючими власниками позицій

### Підвищений переклад

Відобразити файли переведено вперед:

- **Попередня економія**: Кожна цільова мова зберігається відразу після перекладу, зменшення тиску пам'яті
- **Block-level tracking**: відстеження стану перекладу за блок
- **Селектрична птиця**: Тільки не вдалося перекласти блоки на наступний пробіг
- **Metadata persistence**: Translation state survives application restarts

### Розширена птиця логіка

Три рівні стійкості:

1. **HHTTP retry** (LibreTranslateService): 5 спроб з відключенням (1s–5s)
2. **Пошта птиця** (ТрансляціяПослуга): 3 додаткові спроби з 30-ми затримками
3. **Block retry** (DocumentsTranslationService): блоки роз'єму, що надходяться на наступний пробіг

### Звітність SignalR

Звітність по роботі з трубопроводами:

- Кожен етап публікує події
- По-мовному прогресу публікуються як події
- Випадкові події включають детальний контекст (джерело, код помилки, повідомлення)
- Замовляйте замовлення в кожному режимі

## Попереднє сумісність

Всі зміни додаються:

- Виконує код локалізації ()
- Посадове форматування () працює незмінно
- Виконувати формат словника JSON не змінюється
- Неперервна структура маркування
- Повідомлення SignalR використовують однаковий формат

## Міграційна шлях

Не потрібно міграції. Рефакторинг є внутрішнім:

1. Старі зберігалися як посилання, а потім замінили
2. Оновлено для використання нових інтерфейсів
3. Всі наявні споживачі не змінюють

## Покращення продуктивності

- **Використання пам'яті**: Файли, що зберігаються замовчою мовою, замість того, щоб тримати всі пам'яті
- **Faster incremental їде**: Тільки змінені/розміщені блоки розмітки перевантажуються
- **Подивитися видимість**: Реальний хід допомагає діагностувати повільні етапи

## Розширення майбутнього

Плановані поліпшення:

1. **AI fine-tuning** — Post-machine translation review for phrases > 5 words
2. **Адмін автентифікації** — Обмеження сторінок адміністратора для уповноважених користувачів
3. **Dictionary editor** — Web UI for managing localization keys
4. **Translation statistics** — Charts showing translation counts and error rates over time
5. **Custom placeholder syntax** — Support for alternate placeholder formats

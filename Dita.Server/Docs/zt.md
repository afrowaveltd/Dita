# 自動翻譯處的變更摘要

## 概述

此文件概述 Dita自動翻譯服務的所有變更, 包括架构重設、新功能、可觀性改善和地區化增強等 .

## 架构變更

### 已重建后端翻譯服務

由輕量级管弦樂團相接而成:

- ** Backend 翻譯服務 ** 接通管線管線( 伺服器驗證、 相機傳送、 錯誤處理等)
- ** Countries Transferation Service** — 國家名稱同步 (英文) 目標語言
- ** 就地化 翻譯 服務**- JSON 字典同步 (加/去除金鑰)
- **DocumentsTranslationService** — Markdown documentation translation with block-level tracking
- ** SignalRPublisher**-取自SignalR的实时進取報告
- ** 翻譯服務** -- -- 有占位符保存的相關重試

### 福利

- ** 消除所关切的问题**: 每個服務處理一單一翻譯域
- **可保持性**: 有更小的課更能理解和考驗
- ** 延长**: 可通过介面執行新增翻譯目標
- ** 可靠性**:獨立服務能提供更好的故障隔離

### 增強重試邏輯

三等回應能力:

1. ** HTTP 重試** (Libre Translate Services): 有5次取而代之( 1s– 5s)
2. ** 重試** (翻譯: 服務):再作三次, 有30多起延遲
3. **Block retry** (DocumentsTranslationService): Failed Markdown blocks retried on next run

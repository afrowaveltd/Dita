# Резюме изменений в службе автоматического перевода

## Обзор

В этом документе обобщены все изменения, внесенные в службу автоматического перевода Dita, включая рефакторинг архитектуры, новые функции, улучшения видимости и улучшения локализации.

## Архитектура меняется

### Обновленный BackendTranslationService

Монолит был разложен на четыре специализированные службы, координируемые легким оркестратором:

- **BackendTranslationService** — Трубопроводный оркестратор (проверка сервера, делегирование сцены, обработка ошибок)
- **CountriesTranslationService** — синхронизация названий стран (английский язык → целевой язык)
- **LocalizationTranslationService** — синхронизация словаря JSON (добавленные/удаленные ключи)
- **DocumentsTranslationService** — перевод документации с блок-уровня
- **SignalRPublisher** - Отчетность о прогрессе в режиме реального времени через SignalR
- **TranslationRetryService** — Stage-level retry с сохранением заполнителя

### Преимущества

- ** Разделение проблем**: Каждая услуга обрабатывает один домен перевода
- **Устойчивость**: Меньшие классы легче понять и проверить
- ** Расширяемость**: Новые цели перевода могут быть добавлены с помощью интерфейса
- ** Надежность**: Независимые услуги обеспечивают лучшую изоляцию от неисправностей

## Новые особенности

### Мониторинг перевода Live Translation Monitor

** Расположение**:

Новая страница администратора, которая обеспечивает видимость в режиме реального времени в конвейере перевода:

- Отображает все сигналы R события по мере их возникновения
- Цветовые типы сообщений (синий = начальный, зеленый = завершенный, красный = ошибка)
- Статус подключения баннер с автоподключением
- Счетчик сообщений и экспорт в JSON

### Названы обладатели мест

В настоящее время система локализации поддерживает названные заполнители () для улучшения грамматики на разных языках:

```csharp
// Usage in code
var message = Localizer["WelcomeMessage", new Dictionary<string, string>
{
    ["userName"] = "John",
    ["count"] = "5"
}];
// Result: "Hello John, you have 5 new messages"
```

Особенности:
- Значения, предоставленные во время выполнения или сохраненные в
- Автоматическая маскировка/восстановление во время перевода для предотвращения коррупции
- Обратно совместим с существующими позиционными заполнителями

### Дополнительный перевод

Файлы Markdown переводятся постепенно:

- **Сохранение языка**: Каждый целевой язык сохраняется сразу после перевода, снижая давление памяти
- **Отслеживание на уровне блока**: статус перевода треков на блок
- **Селективная повторная запись**: Только неудавшиеся блоки переводятся в следующем цикле
- **Постоянство Метадата**: состояние перевода выживает после перезапуска приложения

### Улучшенная логика Retry

Три уровня устойчивости:

1. **HTTP retry** (LibreTranslateService): 5 попыток с экспоненциальным выключением (1s-5s)
2. **Стадия повторного использования** (TranslationRetryService): 3 дополнительные попытки с 30-кратными задержками
3. **Block retry** (Служба перевода документов): Неудачные блоки Markdown будут восстановлены в следующем запуске

### SignalR сообщает

Отчетность о ходе всех трубопроводных операций в режиме реального времени:

- Каждый этап публикует события
- Пер-языковой прогресс публикуется как события
- События ошибки включают подробный контекст (источник, код ошибки, сообщение)
- Номера последовательностей гарантируют порядок в каждом запуске

## Обратная совместимость

Все изменения являются аддитивными:

- Существующий код локализации () работает без изменений
- Позиционное форматирование () работает без изменений
- Существующий формат словаря JSON не изменился
- Существующая структура Markdown неизменна
- Сигнал R-сообщения используют одинаковый формат

## Миграционный путь

Миграция не требуется. Рефакторинг является внутренним:

1. Старый был сохранен в качестве ссылки, а затем заменен
2. Регистрации DI были обновлены для использования новых интерфейсов
3. Все существующие потребители не видят изменений

## Повышение производительности

- ** Сокращение использования памяти**: Файлы сохраняются на одном языке, а не хранятся в памяти
- **Быстрый прирост Бежит**: Только измененные/неудавшиеся блоки Markdown переводятся
- ** Улучшенная видимость**: Прогресс в реальном времени помогает диагностировать медленные стадии

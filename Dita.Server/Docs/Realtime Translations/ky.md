# Чыныгы убакыттагы котормолор

Бул документ автоматтык котормо түтүктөрү үчүн түз эфирде сыноо киргизүү катары бар. Бул файлга киргизилген ар кандай өзгөрүүлөр кийинки пландаштырылган мөөнөттө бардык максаттуу тил файлдарын кайра которууга алып келет.

## Архитектуранын жалпы көрүнүшү

Котормо түтүктөрү модулдук архитектурага айландырылган, төрт адистештирилген суб-кызмат жеңил оркестр тарабынан координацияланган:

- **BackendTranslationService** — Orchestrates the entire pipeline, handles server validation, and delegates work to sub-services.
- **CountriesTranslationService** — Synchronizes country names from `countries.json` into per-language dictionaries.
- **LocalizationTranslationService** — Detects added/removed keys in the default JSON dictionary and translates them into target languages.
- **DocumentsTranslationService** — Translates Markdown documentation files with per-block tracking and metadata.

Ар бир суб-кызмат көз карандысыз иштейт жана SignalR аркылуу прогрессти реалдуу убакытта билдирет.

## Кызматтын эмне кылганы

Кызмат график боюнча иштейт жана беш баскычтуу түтүктү аткарат: серверди текшерүү, өлкөнү синхрондоштуруу, JSON сөздүгүн синхрондоштуруу, Markdown файлын которуу жана натыйжаларды сактоо. Ар бир баскыч SignalR аркылуу структураланган реалдуу убакыт прогресс окуяларын чыгарат, ошентип байланышкан кардарлар иштин жүрүшүндө ээрчип жүрө алышат.

## Түтүктүн баскычтары

### 1-этап: текшерүү тейлөөчүлөр

Котормо иштери башталганга чейин, кызмат бардык алдын ала шарттардын аткарылганын текшерет:

- Конфигурация бөлүмү бар жана жарактуу болушу керек.
- LibreTranslate сервери кабыл алынуучу кечиктирүү чегинде жооп бериши керек.
- Котормо серверинде жеткиликтүү тилдердин тизмеси келтирилген.
- Конфигурацияланган демейки тил бул тизмеде болушу керек.
- Ар бир колдоого алынган тил үчүн жоголгон жергиликтүү JSON файлдары автоматтык түрдө түзүлөт.

Эгерде кандайдыр бир текшерүү ийгиликсиз болсо, түтүк дароо токтоп калат жана билдирүү чыгарылат.

### 2-этап: Трансляциялык өлкөлөр

Өлкө аталыштары окулуучу каталогдон () локалдаштыруу JSON сөздүктөрүнө синхрондоштурулат.

- Эгерде өтүнмөнүн демейки тили англис тили болсо, анда ар бир өлкөнүн аталышы котормосуз сакталат.
- Эгерде демейки тил башка тил болсо, анда англис тилинин аталышы алгач ошол тилге которулат жана натыйжада демейки сөздүктөгү жазуу болот.
- Демейки сөздүктү жаңырткандан кийин, ар бир максаттуу тил сөздүгүндөгү жоголгон өлкөнүн ар бир жазуусу которулат жана сакталат ** тилге дароо **.
- Буга чейин которулган жазуулар өзгөртүүлөрсүз сакталат.
- Эгерде котормо ийгиликсиз болсо, анда кызмат кийинки тилге өтүүдөн мурун 30 секунд кечиктирүү менен 3 жолу кайра өтөт.

### 3-этап: Транслат Жон Филдер

Кызмат учурдагы демейки локалдаштыруу сөздүгүн мурунку чуркоодон сакталган сүрөт менен салыштырат:

- **Added keys** — entries present in the current default but absent from the snapshot — are translated into every target language that does not already have a manual entry for that key.
- **Removed keys** — entries present in the snapshot but absent from the current default — are deleted from every target language dictionary.
- Кол менен которулган котормолор ар дайым биринчи орунда турат. Эгерде максаттуу сөздүктө ачкычтын мааниси бар болсо, анда ал жазуу булак эмне дегенине карабастан өзгөрүүсүз калат.
- ** Ар бир максаттуу тил сөздүгү бардык тилдердин аякташын күтпөстөн, котормолору аяктагандан кийин дароо сакталат**.
- Эгерде котормо белгилүү бир тил үчүн ийгиликсиз болсо, анда кызмат автоматтык түрдө кайра жөнөтүлөт. Бир гана туруктуу каталар (мисалы, колдоого алынбаган тил) ошол тилди өткөрүп жиберүүгө алып келет.
- Жүргүзүлгөндөн кийин, учурдагы демейки сөздүк кийинки салыштыруу үчүн жаңы сүрөт катары сакталат.

Бардык сөздүктөр ар дайым алфавиттик тартиптеги ачкычтар менен сакталат жана адам окуй алат.

### 4-этап: Транслат Марштаун Филдер

Кызмат конфигурацияланган документтердин тамырын (дефолт: ) басып өтөт жана ар бир булак файлын рекурсивдүү иштетет:

1. Булак файлынын мазмуну окулат жана SHA-256 хэш эсептелет.
2. A `.translation-meta.json` file next to the source tracks per-language, per-block translation status, enabling **incremental re-translation** of only failed blocks.
3. Мурунку чуркоодон сакталган хэш (булак файлынын жанындагы файлда же убактылуу резервдик жерде сакталган) учурдагы хэш менен салыштырылат.
4. Ар бир максаттуу тил үчүн тиешелүү файлдын структуралык бүтүндүгү да текшерилет.
5. Жоголгон, эскирген хэшке ээ болгон, структураны текшерүүдөн өтпөй калган же которулбаган блокторду камтыган ар бир максаттуу файл кайра которуу үчүн кезекке турат.
6. **Each target language is translated and saved independently** — if Czech succeeds but French fails, the Czech file is still written to disk.
7. Ийгиликтүү которулган файлдар дискке жазылуудан мурун булак менен структуралык теңдик үчүн тастыкталат (бирдей аталыштардын саны, тизме элементтери, код блоктору, блокквоттор, шилтемелер, кара түстөгү маркерлер жана HTML тегдери).
8. Эгерде булак үчүн бардык максаттуу файлдар ийгиликтүү болсо, жаңы хэш булактын жанында сакталат. Эгерде булактын жанында жазуу ийгиликсиз болсо (мисалы, окуу үчүн гана жайгаштырууларда), хэш убактылуу каталогго кайтып келет.
9. Эгерде максаттуу котормо валидацияланбаса, метамаалыматтар ошол блокторду которулбаган деп белгилейт, ошондуктан алар кийинки чуркоодо кайра текшерилет.

### 5-этап: Жыйынтыктарды сактоо

Консолидацияланган документ чогултулуп, жарыяланат. Ага төмөнкүлөр кирет:

- UTC иштөө баштоо жана бүтүрүү убактысы.
- Сакталган жергиликтүү JSON файлдарынын, сакталган Markdown файлдарынын, сакталган хэш файлдарынын жана резервдик хэш жазууларынын саны.
- Жүргүзүү учурунда чогултулган сактоо каталары.
- Тилге котормо статистикасы (трансляцияланган сан, жоголгон сан, каталардын саны).

## Котормонун кайра иштетүү логикасы

Бул түтүк эки деңгээлдеги туруктуулукту ишке ашырат:

### Сценалык деңгээлдеги ретри (TranslationRetryService)

- Эгерде котормо өтүнүчү LibreTranslate ички ретрилеринен кийин ийгиликсиз болсо, анда 30 секунд кечиктирүү менен 3 кошумча этап деңгээлиндеги ретрилерди аткарат.
- "Тексттеги ""жер ээлери"" деген аталыш котормодон мурун убактылуу коопсуз белгилер менен алмаштырылат жана андан кийин калыбына келтирилет, бул максаттуу тилдерде туура грамматиканы камсыз кылат.".

### Тилди текшерүү

- Максаттуу тилге которуудан мурун, кызмат тилди котормо сервери тарабынан колдоого алынарын текшерет.
- Колдонулбаган тилдерди эскертүү менен өткөрүп жиберип, кайра-кайра ийгиликсиз аракеттерди жасоого жол берилбейт.

### Блоктук деңгээлдеги кайра иштетүү

- Маркировкалоо котормолору блок-блок (баш тамгалар, абзацтар, тизме элементтери) жүргүзүлөт.
- Эгерде жеке блок котормодо ийгиликсиз болсо, анда ал метамаалымат файлында которулбаган деп белгиленет жана кийинки түтүктөрдө кайра текшерилет.
- Кызмат ар бир булак Markdown файлынын жанындагы файлдардагы тилге, блокко карата абалды көзөмөлдөйт.

## Тирүү котормо панели

Server долбоору SignalR хабына туташкан жана бардык түтүктөр окуяларын реалдуу убакытта көрсөткөн администратордук баракчаны камтыйт.

- Байланыштын абалын, билдирүүлөрдүн санын жана бардык окуялардын жандуу таблицасын көрсөтөт.
- Түстүү коддолгон саптар: сахнаны баштоо үчүн көк, бүтүрүү үчүн жашыл, каталар үчүн кызыл.
- Бул азык-түлүктү тазалоону жана бардык билдирүүлөрдү ЖСОНго экспорттоону колдойт.
- Эгерде байланыш төмөндөп кетсе, автоматтык түрдө экспоненциалдык резервдик байланыш менен кайра байланышат.

## Дизайн принциптери

- ** Модулдук **: Ар бир котормо маселеси өзүнчө тейлөө жана текшерүү үчүн өзүнчө кызмат көрсөтөт.
- ** Кошумча туруктуулук**: Сөздүктөр жана Markdown файлдары котормодон кийин дароо тилге сакталат, эс тутумдун басымын азайтат жана эртерээк кайтарым байланыш берет.
- **Resilience**: Multiple retry levels (HTTP, stage, block) ensure transient failures do not block the pipeline.
- ** Мамлекеттик издөө**: Бир файлга метамаалыматтар () жана хэш файлдары кийинки чуркоолордо так кошумча иштөөгө мүмкүндүк берет.
- ** Чыныгы убакыттагы көрүнүш**: Ар бир маанилүү операция SignalR аркылуу мониторинг жана оңдоо үчүн билдирилет.
- ** Кол менен которулган котормолор ар дайым автоматтык кошумчаларга караганда артыкчылыктуу. **

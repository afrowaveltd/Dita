# Чыныгы убакыттагы котормолор

Бул документ автоматтык котормо түтүктөрү үчүн түз эфирде сыноо киргизүү катары бар.

## Кызматтын эмне кылганы

Кызмат график боюнча иштейт жана котормо серверин, конфигурациясын жана жеткиликтүү тилдерди котормо иши башталганга чейин текшерет.

Валидациялоо баскычынан кийин, ал окуу үчүн гана өлкөлөрдүн каталогунан стандарттык локалдаштыруу JSON сөздүктөрүнө өлкөнүн аталыштарын синхрондоштурат. Эгерде өтүнмөнүн демейки тили англис тили болсо, анда өлкөнүн жазуусу ачкычтын маанисине барабар сакталат. Эгер демейки тил башкача болсо, англис өлкөсүнүн аталышы алгач демейки тилге которулат, андан кийин гана демейки сөздүктө ачкычтын мааниси бирдей деп сакталат.

Андан кийин, кызмат учурдагы демейки локалдаштыруу сөздүгүн мурунку чуркоонун сакталган сүрөтү менен салыштырат. Жаңы кошулган жазуулар максаттуу тилдерге ачкыч жок болгондо гана которулат, ошондуктан кол менен котормолор артыкчылык берет. Бардык максаттуу сөздүктөрдөн алынып салынган жазуулар алынып салынат, бул бүтүндөй топтомду ырааттуу сактайт.

Акыр-аягы, кызмат Маркдаун дарактарынын конфигурацияланган документтеринин тамырын сканерлейт. Ар бир тема папкасында демейки тилдин атынан аталган булак файлы, мисалы, en.md болушу керек. Кызмат булак файлын хэштейт, өзгөрүүлөрдү аныктайт, жетишпеген же эскирген максаттуу Markdown файлдарын которат жана булак файлынын жанында учурдагы хэш сактайт. Эгерде хэшти булак файлынын жанына жазуу мүмкүн болбосо, анда ал убактылуу сакталат.

## Кызматтын өнүгүшү тууралуу отчеттор

Backend бир билдирүү конвертин колдонуу менен локалдаштыруу борбору аркылуу жалпы SignalR билдирүүлөрүн чыгарат. Ар бир билдирүү билдирүү түрүн, учурдагы процесстин баскычын, UTC убакыт белгисин, тексттик кыскача маалыматты жана факультативдик этапка мүнөздүү жүктү камтыйт.

Учурдагы баскычтар төмөнкүлөр:

- текшерүүчүлөр
- Транслат өлкөлөр
- Транслат Жон Филдер
- TranslateMarkdown булалары
- Жыйынтыктарды сактоо

Адатта, билдирүү агымы сахнада башталат, сахнада бүтөт жана түтүктө бүтөт. Эгерде этап ийгиликсиз болсо, анда билдирүү ката катары белгиленет жана бирдиктүү ката коддору бар структураланган ката маалыматтарын камтыйт.

## Дизайн принциптери

LibreTranslate серверин ашыкча жүктөөдөн качуу үчүн котормолор ырааттуу түрдө иштетилет.

Локализация JSON сөздүктөрү ар дайым алфавиттик сорттолгон ачкычтар жана форматталган JSON менен сакталат.

Мурунку демейки сөздүктүн сүрөтү туруктуу сакталат, ошондуктан колдонмону кайра баштоо өзгөрүүлөрдү көзөмөлдөөнү жоготпойт.

** Кол менен которулган котормолор ар дайым автоматтык кошумчаларга караганда артыкчылыктуу. **

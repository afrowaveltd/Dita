# Переклади

Цей документ існує в якості джерела даних для автоматичного перекладу.

## Що таке сервіс

Послуга працює на графіку та діє на сервер перекладу, налаштування та наявні мови перед початком роботи перекладу.

Після валідації, він синхронізує назви країни з каталогу читаних країн в стандартну локалізацію словників JSON. Якщо мова за замовчуванням програми англійською мовою, запис країни зберігається як ключове значення. Якщо мова за замовчуванням відрізняється, ім'я англійською мовою спочатку перекладається на мову за замовчуванням, а тільки потім зберігається як ключове значення дорівнює словнику за замовчуванням.

Далі служба порівнює поточний словник локалізації за замовчуванням з збереженим знімком з попереднього запуску. Додані записи переведені на цільові мови тільки тоді, коли ключ не існує, тому ручні переклади зберігають пріоритет. Вилучені записи видаляються з усіх цільових словників, щоб зберегти весь набір послідовно.

Нарешті, служба сканування налаштовує корені документації для розмітки дерев. Кожна папка тема повинна містити вихідний файл, який називається мовою за замовчуванням, наприклад, en.md. Послуга має файли, що вихідного коду, виявляє зміни, переводить відсутні або застарілі файли, і зберігає поточний хеш поруч із вихідним файлом. Якщо записувати хеш поруч із вихідним файлом неможливе, він повертається на тимчасове зберігання.

## Як прогрес звітів про послуги

Додаток випромінює загальні повідомлення SignalR через концентратор локалізації, використовуючи один конверт повідомлення. Кожне повідомлення несе тип повідомлення, поточний етап процесу, часовий список UTC, текстовий підсумок та додаткове навантаження на сцені.

Поточні етапи:

- Послуги
- ПерекладКолуси
- ПерекладJsonFiles
- English, Українська, Français..
- СтупіньРезультати

Розпочато типовий потік повідомлень, завершено етап та завершено. Якщо етап не вдається, повідомлення позначено як помилка і включає в себе структуровану інформацію про помилки з кодами єдиного помилки.

## Принципи проектування

Переклади обробляються послідовно, щоб уникнути перевантаження сервера LibreTranslate.

Локалізація JSON dictionaries завжди зберігається з абетально відокремленими ключами та форматованою JSON для зручності обслуговування.

Попереднє завантаження словника за замовчуванням зберігається наполегливо, так що решта програми не втратить відстеження змін.

**Універсальні переклади завжди мають пріоритет над автоматичними доповненнями.**

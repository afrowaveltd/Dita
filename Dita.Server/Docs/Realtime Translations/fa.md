# ترجمه های زمان واقعی

این سند به عنوان یک ورودی آزمایشی زنده برای خط لوله ترجمه خودکار وجود دارد.

## چه خدماتی انجام می دهد

این سرویس در یک برنامه اجرا می شود و سرور ترجمه، پیکربندی و زبان های موجود را قبل از شروع کار ترجمه معتبر می کند.

پس از مرحله اعتبار، نام های کشور را از کاتالوگ کشورهایی که تنها خوانده شده اند، به محلی سازی JSON Diactionaries همگام می کند. اگر زبان پیش فرض درخواست انگلیسی باشد، ورود کشور به عنوان ارزش برابر کلیدی ذخیره می شود. اگر زبان پیش فرض متفاوت باشد، نام کشور انگلیسی برای اولین بار به زبان پیش فرض ترجمه می شود و تنها پس از آن به عنوان ارزش کلیدی در فرهنگ لغت به طور پیش فرض ذخیره می شود.

سپس، این سرویس فرهنگ لغت محلی سازی فعلی را با عکس فوری ذخیره شده از اجرای قبلی مقایسه می کند. ورودی های جدید به زبان های هدف فقط زمانی که کلید وجود ندارد ترجمه می شوند، بنابراین ترجمه های دستی اولویت دارند. ورودی های حذف شده از تمام مجازات های هدف حذف می شوند تا کل مجموعه را ثابت نگه دارند.

در نهایت، این سرویس ریشه های مستندات پیکربندی شده را برای درختان مارک معکوس اسکن می کند. انتظار می رود هر پوشه موضوعی شامل یک فایل منبع به نام زبان پیش فرض مانند en.md باشد. این سرویس هش می کند که فایل منبع، تغییرات را تشخیص می دهد، فایل های مارک معکوس را گم یا منسوخ می کند و هش فعلی را در کنار فایل منبع ذخیره می کند. اگر نوشتن هش در کنار فایل منبع امکان پذیر نباشد، به ذخیره سازی موقت باز می گردد.

## چگونه خدمات گزارش پیشرفت

Backend پیام های سیگنال R عمومی را از طریق مرکز محلی سازی با استفاده از یک پاکت پیام منتشر می کند. هر پیام دارای یک نوع پیام، مرحله فرایند فعلی، یک جدول زمانی UTC، خلاصه متن و اختیاری مرحله خاص است.

مراحل فعلی عبارتند از:

- گزینه CheckServers
- ترجمه: ترجمه کشور
- ترجمه: ترجمه JsonFiles
- آرشیوهای برچسب ها
- دانلود بازی Storing Results

جریان پیام معمولی مرحله شروع، مرحله تکمیل شده و خط لوله تکمیل شده است. اگر یک مرحله شکست بخورد، پیام به عنوان یک خطا مشخص می شود و شامل اطلاعات خطای ساختاری با کدهای خطای یکپارچه می شود.

## اصول طراحی

ترجمه ها به طور متوالی پردازش می شوند تا از اضافه بار سرور LibreTranslate جلوگیری کنند.

Localization JSON Diactionaries همیشه با کلید های مرتب و فرمت شده JSON برای نگهداری آسان تر ذخیره می شود.

چشم انداز دیکشنری پیش فرض قبلی به طور مداوم ذخیره شده است، بنابراین یک راه اندازی مجدد از برنامه ردیابی تغییر را از دست نمی دهد.

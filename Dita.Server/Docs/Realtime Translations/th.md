# แปลภาษาแบบเรียลไทม์

เอกสารนี้ใช้เป็นตัวทดสอบแบบสดสําหรับส่งค่าไปทดสอบสําหรับท่อแปลภาษาอัตโนมัติ.

## สิ่งที่บริการทํา

บริการ นี้ ดําเนิน งาน ตาม ตาราง เวลา และ ทํา ให้ เครื่องแม่ข่าย การ แปล, การปรับแต่ง, และ ภาษา ที่ มี อยู่ ก่อน ที่ งาน แปล จะ เริ่ม ต้น.

หลังจากที่ขั้นตอนการตรวจสอบจะประสาน ชื่อประเทศจากแคตตาล็อก ประเทศเท่านั้น อ่านเป็นมาตรฐานพจนานุกรม Json หากภาษาปริยายของโปรแกรมเป็นภาษาอังกฤษ รายการในประเทศจะถูกเก็บไว้เป็นกุญแจเท่ากับค่า หากภาษาปริยายแตกต่างไป ชื่อประเทศอังกฤษจะถูกแปลเป็นภาษาปริยายก่อน จากนั้นจะเก็บไว้เป็นค่ากุญแจที่เท่ากันในพจนานุกรมปริยายเท่านั้น.

ถัดไป บริการจะเปรียบเทียบพจนานุกรมระบบปริยายในปัจจุบัน กับภาพที่เก็บไว้จากการทํางานครั้งก่อน ส่วน ที่ เพิ่ม เข้า มา ใหม่ ๆ จะ ถูก แปล เป็น ภาษา เป้า เฉพาะ เมื่อ กุญแจ ยัง ไม่ มี อยู่ ดัง นั้น การ แปล แบบ คู่มือ จึง สําคัญ กว่า. รายการที่ลบออกไปทั้งหมด ถูกลบออกจากพจนานุกรมเป้าหมายทั้งหมด เพื่อรักษาเซตทั้งหมดให้สอดคล้องกัน.

ใน ที่ สุด การ สแกน ของ บริการ ก็ ปรับ ราก เอกสาร ของ ต้น ไม้ มาร์ ดาวน์. คาดว่าจะมีแฟ้มต้นฉบับที่มีชื่อตามภาษาปริยาย เช่น en.md บริการมีหน่วยเป็นแฟ้มต้นทาง, ตรวจพบการเปลี่ยนแปลง, แปลแฟ้มปลายทางที่สูญหาย หรือแฟ้ม markดาวน์ที่หมดอายุแล้ว, และเก็บข้อมูล shh ในปัจจุบันไว้ถัดจากแฟ้มต้นทาง หาก เขียน แฮช ซึ่ง อยู่ ถัด ไป จาก แฟ้ม ที่ มา จาก แหล่ง นั้น เป็น ไป ไม่ ได้ ก็ จะ กลับ ไป เป็น ที่ เก็บ ชั่ว คราว.

## รายงานความคืบหน้าของบริการ

แบ็คเอนต์จัดการจดหมายทั่วไป ทุกข้อความมีชนิดของข้อความ, ระยะกระบวนการปัจจุบัน, ระยะเวลาแบบยูทีซี, การสรุปข้อความ, และตัวเลือกการจ่ายเงินบนเวที.

ขั้น ตอน ปัจจุบัน คือ:

- เครื่องตรวจสอบ
- การแปล
- แฟ้มแปลภาษา Jon
- แปลแฟ้มการไล่ระดับสี
- การ ขโมย

โดย ทั่ว ไป การ ส่ง ข้อ ความ จะ เริ่ม ต้น ขั้น ตอน, การ สร้าง เวที เสร็จ สมบูรณ์, และ การ ส่ง ทาง ท่อ ส่ง น้ํา ก็ เสร็จ สมบูรณ์. หากเวทีล้มเหลว จดหมายนี้จะถูกทําเครื่องหมายว่าผิดพลาด รวมถึงโครงสร้างข้อมูลที่ผิดพลาดด้วย.

## หลักการการออกแบบ

มี การ ดําเนิน การ แปล แบบ ต่าง ๆ กัน เพื่อ หลีก เลี่ยง การ ทํา ให้ เซิร์ฟเวอร์ LibreTranslate โอเวอร์โหลด มาก เกิน ไป.

พจนานุกรม เจ สัน ใน ท้อง ถิ่น มัก จะ ถูก เก็บ ไว้ พร้อม ด้วย กุญแจ ที่ เรียง ตาม ตัว อักษร และ ปรับ แบบ เจ สัน เพื่อ การ บํารุง รักษา ที่ ง่าย ขึ้น.

การจับภาพพจนานุกรมปริยายก่อนหน้านี้ จะถูกเก็บไว้อย่างต่อเนื่อง ดังนั้นการเริ่มการทํางานโปรแกรมใหม่ ๆ จึงไม่มีการสูญเสียการติดตามการเปลี่ยนแปลง.

# स्वचालित अनुवाद सेवा में परिवर्तन का सारांश

## अवलोकन

यह दस्तावेज़ डीटा स्वचालित अनुवाद सेवा में किए गए सभी परिवर्तनों को संक्षेप में प्रस्तुत करता है, जिसमें आर्किटेक्चर रिफैक्टरिंग, नई सुविधाओं, अवलोकन सुधार और स्थानीयकरण वृद्धि शामिल है।.

## वास्तुकला परिवर्तन

### Refactored backendtranslation Service

मोनोलिथिक को हल्के ऑर्केस्ट्रेटर द्वारा समन्वित चार विशिष्ट सेवाओं में विघटित किया गया है:

- **BackendTranslationService** — Pipeline orchestrator (server validation, stage delegation, error handling)
- **CountriesTranslationservice** - देश का नाम सिंक्रनाइज़ेशन (अंग्रेजी → लक्ष्य भाषा)
- **LocalizationTranslationservice ** - JSON शब्दकोश सिंक्रनाइज़ेशन (added/removed key)
- **DocumentTranslationService** - ब्लॉक-लेवल ट्रैकिंग के साथ मार्कडाउन प्रलेखन अनुवाद
- **SignalRPublisher** - सिग्नलआर के माध्यम से रियल टाइम प्रगति रिपोर्टिंग
- **TranslationRetryService** - स्टेज लेवल रिट्रीट, प्लेसहोल्डर प्रोटेक्शन के साथ

### लाभ

- **Separation of concerns**: Each service handles a single translation domain
- **Maintainability**: Smaller classes are easier to understand and test
- **Extensibility**: New translation targets can be added via interface implementation
- **Reliability**: Independent services provide better fault isolation

## नई सुविधाएँ

### लाइव अनुवाद मॉनिटर

**Location**: `/Admin/LiveTranslation`

एक नया व्यवस्थापक पृष्ठ जो अनुवाद पाइपलाइन में वास्तविक समय की दृश्यता प्रदान करता है:

- सभी सिग्नलआर घटनाओं को प्रदर्शित करता है क्योंकि वे होते हैं
- रंग-कोडित संदेश प्रकार (नीला = शुरू, हरा = पूर्ण, लाल = आतंक)
- ऑटो-रिकनेक्ट के साथ कनेक्शन स्टेटस बैनर
- संदेश काउंटर और JSON को निर्यात करें

### नामित प्लेसहोल्डर

स्थानीयकरण प्रणाली अब विभिन्न भाषाओं में बेहतर व्याकरण के लिए नामित प्लेसहोल्डर () का समर्थन करती है:

```csharp
// Usage in code
var message = Localizer["WelcomeMessage", new Dictionary<string, string>
{
    ["userName"] = "John",
    ["count"] = "5"
}];
// Result: "Hello John, you have 5 new messages"
```

सुविधाएँ:
- रनटाइम पर प्रदान किए गए प्लेसहोल्डर मूल्य या रनटाइम में संग्रहीत
- भ्रष्टाचार को रोकने के लिए अनुवाद के दौरान स्वचालित मास्किंग / बहाली
- पिछड़े मौजूदा स्थिति वाले प्लेसहोल्डरों के साथ संगत

### गहन अनुवाद

मार्कडाउन फ़ाइलों को वृद्धि से अनुवादित किया गया है:

- **Per-language saving**: Each target language is saved immediately after translation, reducing memory pressure
- **Block-level track**: ट्रैक्स अनुवाद स्थिति प्रति ब्लॉक
- **Selective retry**: Only failed blocks are re-translated on the next run
- **Metadata persistence**: Translation state survives application restarts

### बढ़ी हुई रेट्री लॉजिक

लचीलापन के तीन स्तर:

1. **HTTP retry** (LibreTranslateService): 5 प्रयास, जिनका एक्सपोनेंशियल बैकऑफ (1s-5s) है।
2. ** स्टेज रिट्री ** (TranslationRetryService): 30s देरी के साथ 3 अतिरिक्त प्रयास
3. **Block retry** (DocumentsTranslationService): विफल मार्कडाउन ब्लॉक अगले रन पर वापस आ गया

### सिग्नलआर रिपोर्टिंग

सभी पाइपलाइन कार्यों के लिए रीयल-टाइम प्रगति रिपोर्टिंग:

- प्रत्येक चरण घटनाओं को प्रकाशित करता है
- प्रति भाषा प्रगति घटनाओं के रूप में प्रकाशित
- त्रुटि घटनाओं में विस्तृत संदर्भ (स्रोत, त्रुटि कोड, संदेश) शामिल हैं।
- अनुक्रम संख्या प्रत्येक रन के भीतर आदेश की गारंटी

## बैकवर्ड संगतता

सभी परिवर्तन additive हैं:

- मौजूदा स्थानीयकरण कोड () अपरिवर्तित काम करता है
- पोजीशनल प्रारूपण (Pageal formatting) unchanged काम करता है
- मौजूदा JSON शब्दकोश प्रारूप अपरिवर्तित है
- मौजूदा मार्कडाउन संरचना अपरिवर्तित है
- सिग्नलआर संदेश उसी प्रारूप का उपयोग करते हैं

## प्रवासन पथ

कोई प्रवास की आवश्यकता नहीं है। रिफैक्टरिंग आंतरिक है:

1. पुराने को एक संदर्भ के रूप में संरक्षित किया गया और फिर प्रतिस्थापित किया गया।
2. डीआई पंजीकरण को नए इंटरफेस का उपयोग करने के लिए अद्यतन किया गया था
3. सभी मौजूदा उपभोक्ताओं को कोई बदलाव नहीं

## प्रदर्शन सुधार

- **Reduced memory usage**: Files saved per-language immediately instead of holding all in memory
- **Faster incremental runs**: Only changed/failed Markdown blocks are re-translated
- **Better visibility**: Real-time progress helps diagnose slow stages

## भविष्य में वृद्धि

योजनाबद्ध सुधार:

1. **AI fine-tuning** - वाक्यांशों के लिए पोस्ट-मशीन अनुवाद समीक्षा > 5 शब्द
2. **Admin प्रमाणीकरण** - अधिकृत उपयोगकर्ताओं के लिए प्रतिबंधित व्यवस्थापक पृष्ठ
3. ** शब्दकोश संपादक ** - स्थानीयकरण कुंजी के प्रबंधन के लिए वेब यूआई
4. **Translation statistics** — Charts showing translation counts and error rates over time
5. ** कस्टम प्लेसहोल्डर सिंटैक्स ** - वैकल्पिक प्लेसहोल्डर प्रारूपों के लिए समर्थन

## संपर्क

# Автоматтык котормо кызматына киргизилген өзгөртүүлөрдүн кыскача баяндамасы

## Жалпы көрүнүш

Бул документте Дита автоматтык котормо кызматына киргизилген бардык өзгөртүүлөр, анын ичинде архитектураны кайра иштетүү, жаңы өзгөчөлүктөр, байкоо жүргүзүү мүмкүнчүлүгүн жакшыртуу жана локалдаштырууну жакшыртуу кыскача баяндалат.

## Архитектуранын өзгөрүшү

### Рефактордук арткы котормо кызматы

Монолиттик оркестр жеңил оркестр тарабынан координацияланган төрт адистештирилген кызматка бөлүнгөн:

- **BackendTranslationService** — Pipeline orchestrator (server validation, stage delegation, error handling)
- ** Өлкөлөрдү которуу кызматы** Өлкө аталыштарын синхрондоштуруу (англисче → максаттуу тил)
- ** Локалдаштыруу Котормо Кызмат** JSON сөздүгүнүн синхрондоштурулушу (кошумчаланган/ алынып салынган ачкычтар)
- **DocumentsTranslationService** — Markdown documentation translation with block-level tracking
- **SignalRPublisher** SignalR аркылуу реалдуу убакыттагы прогресс жөнүндө отчет берүү
- **TranslationRetryService** — Stage-level retry with placeholder preservation

### Пайдасы

- ** Кызыкчылыктарды бөлүштүрүү**: Ар бир кызмат бир котормо доменди иштетет
- ** Туруктуулук**: Кичинекей класстарды түшүнүү жана текшерүү оңой
- ** Кеңейтүү**: Жаңы котормо максаттары интерфейсти ишке ашыруу аркылуу кошулушу мүмкүн
- **Reliability**: Independent services provide better fault isolation

## Жаңы өзгөчөлүктөр

### Тирүү котормо монитору

** Локация**:

Котормо түтүктөрүнө реалдуу убакыт режиминде көрүнүүчү жаңы админ баракчасы:

- SignalR окуяларынын бардыгын пайда болгондо көрсөтөт
- Түстүү коддолгон билдирүү түрлөрү (көк = баштапкы, жашыл = толук, кызыл = ката)
- Автоматтык кайра туташуу менен туташуу статусунун баннери
- Билдирүүлөрдү эсептегич жана JSONго экспорттоо

### Аталган жер ээлери

Локализация системасы азыр ар кандай тилдерде грамматикалык жактан жакшыртуу үчүн аталган жер ээлерин колдойт:

```csharp
// Usage in code
var message = Localizer["WelcomeMessage", new Dictionary<string, string>
{
    ["userName"] = "John",
    ["count"] = "5"
}];
// Result: "Hello John, you have 5 new messages"
```

Өзгөчөлүктөрү:
- Жүргүзүү учурунда берилген же сакталган жер ээсинин маанилери
- Коррупцияны алдын алуу үчүн котормо учурунда автоматтык маскалоо же калыбына келтирүү
- Учурдагы позиция ээлери менен шайкеш келген артка карай

### Кошумча котормо

Маркировкалоо файлдары акырындык менен которулат:

- ** Тилге үнөмдөө**: Ар бир максаттуу тил котормодон кийин дароо сакталат, эс тутумдун басымы төмөндөйт
- **Block-level tracking**: `.translation-meta.json` tracks translation status per block
- ** Селективдүү кайра иштетүү**: Кийинки чуркоодо ийгиликсиз блоктор гана кайра которулат
- ** Метамаалыматтардын туруктуулугу**: Котормо абалы колдонмону кайра баштоодон аман калат

### Кайра иштетүү логикасын жакшыртуу

Туруктуулуктун үч деңгээли:

1. **HTTP retry** (LibreTranslateService): 5 attempts with exponential backoff (1s–5s)
2. ** Стаждык ретри** (TranslationRetryService): 30s кечиктирүү менен 3 кошумча аракет
3. ** Блок ретри** (Документтерди которуу кызматы): Кийинки чуркоодо ийгиликсиз белгилөө блоктору кайра сыналды

### SignalR отчету

Бардык түтүктөр операциялары үчүн реалдуу убакыт режиминде прогресс жөнүндө отчет берүү:

- Ар бир баскычта иш-чаралар жарыяланат
- Тилге карата прогресс окуялар катары жарыяланган
- Ката окуяларына майда-чүйдөсүнө чейин контекст (булак, ката коду, билдирүү) кирет
- Кепилдик берүүчү номерлер ар бир чуркоонун ичинде буйрутмаларды берет

## Миграциялык жол

Миграция талап кылынбайт. Рефакторинг ички:

1. Эскиси шилтеме катары сакталып, андан кийин алмаштырылган
2. DI каттоосу жаңы интерфейстерди колдонуу үчүн жаңыртылган
3. Бардык учурдагы керектөөчүлөр эч кандай өзгөрүүлөрдү көрүшпөйт

## Иштин натыйжалуулугун жакшыртуу

- ** Эстутумдун колдонулушунун төмөндөшү**: Тилге сакталган файлдар баарын эстеп калуунун ордуна дароо сакталат
- ** Фастердик кошумча чуркоо**: Өзгөртүлгөн же ишке ашпай калган Markdown блоктору гана кайра которулат
- ** Жакшыраак көрүнүш**: Чыныгы убакыттагы прогресс жай стадияларды аныктоого жардам берет

## Келечектеги жакшыртуулар

Пландаштырылган жакшыртуулар:

1. **AI fine-tuning** — Post-machine translation review for phrases > 5 words
2. ** Админ аутентификация** Админ баракчаларын ыйгарым укуктуу колдонуучуларга гана чектөө
3. **Dictionary editor** — Web UI for managing localization keys
4. **Translation statistics** — Charts showing translation counts and error rates over time
5. **Custom placeholder syntax** — Support for alternate placeholder formats

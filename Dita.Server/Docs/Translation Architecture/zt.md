## 服務分解

### 后端翻譯服務 (orchestrator)

**Responsibilities**:
- 管道生命周期管理(起步、完成、出錯處理)
- Semaphore 相關通數控制( 防止相接跑道)
- 伺服器驗證 (纬度、 語言可用性、 設定等)
- 下放到子服務

** 不包含**:
- 翻譯邏輯
- 特定格式的檔案一/O
- 重試邏輯

### 翻譯服務

**Responsibilities**:
- 从目錄讀取
- 將國家名稱同步到預設地區字典中
- 按目標語言翻譯缺失的國家名稱
- 在翻譯后立即儲存每個目標字典

**Key behaviors**:
- 如果預設語言是英文: 國家名稱被儲存到-is
- 如果預設語言是其它語言:先被翻譯成預設語言的英文名稱
- 每種語言都用自有回取回回取回回取回回取回回取回回取回回取回取回取回回取回取回取回回取回取回取回取回取回取回取回取回回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回取回回取回取回回回回回回取回回回回取回回取回取回回取回回回回回回回回回回回回回回回回回回回回回回回回回回回回回回回回的相的相

### 就地化 翻譯服務

**Responsibilities**:
- 透過比對目前的預設字典與前一個快照來檢測新增/被移除的金鑰
- 將新增的金鑰翻譯到每個目標語言中
- 从每個目標語言中移除已刪除的金鑰
- 儲存快照以做下一個比對

**Key behaviors**:
- 手動翻譯總是优先 (從不覆寫)
- 已加入的金鑰被立即翻譯并儲存到每個語言中
- 已移除的金鑰被立即被刪除( E)
- 在全部語言成功完成后才儲存快照

### 文件翻譯服務

**Responsibilities**:
- 循環地走入已設定的 Markdown 根
- 使用 SHA-256 散列檢測已變更的來源檔案
- 每個區塊的翻譯狀態
- 有相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相接相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相相
- 在翻譯后驗證馬克下結構
- 單獨儲存每個目標語言檔

**Key behaviors**:
- 區塊平方形: 标题、 段落、 列表項目被分解
- 每個語言區塊已成功或失敗的中繼軌道

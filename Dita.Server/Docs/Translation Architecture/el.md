# Αρχιτεκτονική μεταφράσεων

Το παρόν έγγραφο περιγράφει την αρθρωτή αρχιτεκτονική του αυτόματου μεταφραστικού συστήματος της Dita, που εισήχθη για να βελτιώσει τη διατηρησιμότητα, τη δυνατότητα δοκιμής και την ανθεκτικότητα.

## Στόχοι σχεδιασμού

Ο αναπαραγωγέας αντιμετώπισε αρκετές ανησυχίες με το αρχικό μονολιθικό σχέδιο:

- ** Διαχωρισμός των ανησυχιών **: Κάθε τομέας μεταφράσεων (χώρες, λεξικά JSON, Markdown) είναι απομονωμένη.
- **Συναισθηματική επιμονή **: Τα αρχεία αποθηκεύονται ανά γλώσσα αμέσως μετά τη μετάφραση, μειώνοντας τη χρήση μνήμης και παρέχοντας παλαιότερα αποτελέσματα.
- **Αντοχή **: Πολλαπλά επίπεδα επανάληψης χειρίζονται παροδικές αστοχίες χωρίς να μπλοκάρουν ολόκληρο τον αγωγό.
- ** Παρατηρησιμότητα **: Κάθε σημαντική λειτουργία αναφέρεται μέσω του SignalR για παρακολούθηση σε πραγματικό χρόνο.
- ** Επέκταση **: Νέοι στόχοι μεταφράσεων μπορούν να προστεθούν με την εφαρμογή μιας ενιαίας διεπαφής.

## Αποσύνθεση υπηρεσίας

### Σύστημα backendTranslationService (ορχηστρωτής)

** Ευθύνες **:
- Διαχείριση κύκλου ζωής σωληνώσεων (έναρξη, ολοκλήρωση, χειρισμός σφαλμάτων)
- Έλεγχος συμμετρίας με βάση το Σεμαφόρε (προλαμβάνει επικαλυπτόμενες διαδρομές)
- Επικύρωση εξυπηρετητή (γεγονός, διαθεσιμότητα γλώσσας, διαμόρφωση)
- Αντιπροσωπεία στις υπουπηρεσίες

** Δεν περιέχει **:
- Λογική μετάφρασης
- Αρχείο I/O για συγκεκριμένες μορφές
- Επανάληψη λογικής

### ΧώρεςΜετάφρασηΥπηρεσία

** Ευθύνες **:
- Ανάγνωση από τον κατάλογο
- Συγχρονισμός ονομάτων χωρών στο προεπιλεγμένο λεξικό locale
- Μετάφρασε τα χαμένα ονόματα χωρών ανά γλώσσα προορισμού
- Αποθήκευση κάθε λεξικού προορισμού αμέσως μετά τη μετάφραση

** Βασικές συμπεριφορές **:
- Εάν η προεπιλεγμένη γλώσσα είναι η αγγλική: ονόματα χωρών που αποθηκεύονται ως-είναι
- Αν η προεπιλεγμένη γλώσσα είναι άλλη: Αγγλικά ονόματα μεταφρασμένα στην προεπιλεγμένη γλώσσα πρώτα
- Κάθε γλώσσα επεξεργάζεται ανεξάρτητα με τη δική της επανάληψη βρόχου

### ΤοπικοποίησηTranslationService

** Ευθύνες **:
- Ανίχνευση προστιθέμενων/αφαιρούμενων κλειδιών συγκρίνοντας το τρέχον προεπιλεγμένο λεξικό με το προηγούμενο στιγμιότυπο
- Μετάφρασε τα πρόσθετα κλειδιά σε κάθε γλώσσα προορισμού
- Αφαίρεση διαγραμμένων κλειδιών από κάθε γλώσσα προορισμού
- Αποθήκευση στιγμιότυπου για επόμενη σύγκριση

** Βασικές συμπεριφορές **:
- Οι χειρωνακτικές μεταφράσεις έχουν πάντα προτεραιότητα (ποτέ δεν έχουν αντικατασταθεί)
- Τα πρόσθετα κλειδιά μεταφράζονται και αποθηκεύονται ανά γλώσσα αμέσως
- Τα αφαιρούμενα πλήκτρα διαγράφονται αμέσως ανά γλώσσα
- Το στιγμιότυπο αποθηκεύεται μόνο μετά την ολοκλήρωση όλων των γλωσσών με επιτυχία

### Υπηρεσία μετάφρασης εγγράφων

** Ευθύνες **:
- Περπατώντας ρυθμισμένες ρίζες Markdown αναδρομικά
- Ανίχνευση αλλαγμένου πηγαίου αρχείου χρησιμοποιώντας hashes SHA-256
- Παρακολούθηση ανά τετραγωνικό μεταφραστικό καθεστώς
- Μετάφρασε μπλοκ-από-μπλοκ με ανά-μπλοκ retry
- Επικύρωση της δομής σήμανσης μετά τη μετάφραση
- Αποθήκευση κάθε αρχείου γλώσσας στόχου ανεξάρτητα

** Βασικές συμπεριφορές **:
- Σχήμα 2
- Μεταδεδομένα κομμάτια που μπλοκ πέτυχε / απέτυχε ανά γλώσσα
- Τα αποτυχημένα μπλοκ ξαναδοκιμάζονται στην επόμενη εκτέλεση χωρίς επαναμετάδοση επιτυχημένων μπλοκ
- Η επικύρωση της δομής εξασφαλίζει τους αριθμούς πορείας, τις λίστες, τα μπλοκ κωδικών, κ.λπ. πηγή ταιριάσματος

## Επανάληψη στρατηγικής

Το σύστημα εφαρμόζει οπισθοδρομίες σε τρία επίπεδα:

### Επίπεδο 1 — HTTP (LibreTranslateService)

- Μέχρι 5 προσπάθειες με εκθετική αντιστάθμιση (1s, 2s, 3s, 4s, 5s)
- Χειρίζεται χρονόμετρα δικτύου, σφάλματα 5xx και παροδικές αποτυχίες
- Ενσωματώθηκε στις ρυθμίσεις του HTTP πελάτη

### Επίπεδο 2 — Στάδιο (TranslationRetryService)

- Έως 3 προσπάθειες με καθυστερήσεις 30 δευτερολέπτων
- Re-drives το σύνολο της αίτησης μετάφρασης μετά από τις επανεισόδους επιπέδου HTTP είναι εξαντλημένοι
- Σε αυτό το επίπεδο εφαρμόζεται μάσκα και αποκατάσταση τοποθέτων

### Επίπεδο 3 — Τμήμα (Τεκμήρια Υπηρεσία Μετάφρασης)

- Ατομικά μπλοκ σήμανσης που αποτυγχάνουν σημειώνονται σε μεταδεδομένα
- Επανέναρξη αυτόματα στην επόμενη λειτουργία του αγωγού
- Τα επιτυχημένα μπλοκ δεν μεταφράζονται ποτέ ξανά

## Ροή δεδομένων

### Μετάφραση λεξικού JSON

```
[Default Dictionary]
       ↓
[Compare with Snapshot]
       ↓
[Detect Added/Removed Keys]
       ↓
For each target language:
   ├─ Load existing dictionary
   ├─ Apply removals
   ├─ Translate additions (with retry)
   └─ Save dictionary immediately
       ↓
[Save new snapshot]
```

### Μετάφραση μαρκαδόρου

```
[Source File]
       ↓
[Compute Hash]
       ↓
[Compare with stored hash]
       ↓
[Load translation metadata]
       ↓
For each target language:
   ├─ Extract translatable blocks
   ├─ For each block:
   │   ├─ Check metadata (already translated?)
   │   ├─ Translate with retry
   │   └─ Mark success/failure in metadata
   ├─ Reconstruct Markdown
   ├─ Validate structure
   ├─ Save target file
   └─ Save metadata
```

### Μεταφραστική ονομασία χώρας

```
[countries.json]
       ↓
[Build set of country keys]
       ↓
[Update default dictionary]
       ↓
For each target language:
   ├─ Find missing country entries
   ├─ Translate each missing entry (with retry)
   └─ Save dictionary immediately
```

## Κρατική επιμονή

### Στιγμιότυποι

- ** JSON **: Αποθηκευμένο σε ένα αρχείο δίπλα στο προεπιλεγμένο λεξικό (το όνομα ποικίλλει ανάλογα με τον πάροχο αποθήκευσης)
- **Purpose **: Ενεργοποιεί τον πρόσθετο συγχρονισμό με την παρακολούθηση του τι ήταν παρόν στην προηγούμενη εκτέλεση

### Αρχεία Hash

- **Markdown**: δίπλα στο πηγαίο αρχείο
- ** Fallback **: εάν η κύρια θέση είναι μόνο ανάγνωσης
- **Purpose **: Ανιχνεύει τις αλλαγές των πηγών για να αποφευχθεί η περιττή επαναμετάφραση

### Μεταδεδομένα μετάφρασης

- ** σημάδι προς τα κάτω **:
- ** Περιεχόμενα **:
  - Χασίς περιεχομένου πηγής
- Κατάσταση ανά γλώσσα του μπλοκ (άθροισμα των booleans)
- Τελευταία ενημέρωση timestamp
- **Purpose **: Ενεργοποιεί μερική επαναμετάφραση μόνο αποτυχημένων μπλοκ

### Αποθήκευση χώρου

- **Αρχείο **:
- ** Περιεχόμενα**: Λεξικό των πλήκτρων για το όνομα του κατόχου-τιμή ζεύγη
- **Purpose **: Παρέχει προεπιλεγμένες τιμές για τους κατονομαζόμενους κατόχους θέσης σε όλη την εφαρμογή

## Αναφορά SignalR

### Δημοσίευση αφαίρεσης

υπηρεσίες μετάφρασης αποσυνδέσεων από τα ειδικά σημεία SignalR:

```csharp
public interface ISignalRPublisher
{
    Task PublishStageAsync<T>(Guid runId, ProcessStage stage, T data, ...);
    Task PublishMessageAsync(Guid runId, LocalizationMessageType type, ProcessStage stage, ...);
}
```

### Εγγυήσεις ακολουθίας

- Τα μηνύματα μέσα σε ένα μόνο run είναι μονοτονικά αλληλουχούμενα
- Οι αριθμοί ακολουθίας είναι μοναδικοί ανά διαδρομή μέσω
- Οι πελάτες μπορούν να ανιχνεύσουν κενά ή να αναδιατάξει

### Αποτύπωση Hub

```csharp
app.MapHub<LocalizationHub>("/hubs/localization");
```

## Σημεία επέκτασης

### Προσθήκη ενός νέου μεταφραστικού στόχου

1. Δημιουργία νέας διασύνδεσης
2. Εφαρμογή της διεπαφής με λογική που αφορά τον τομέα
3. Εγγραφή σε δοχείο DI
4. Ένεση σε κατασκευαστή
5. Κλήση μετά τα υπάρχοντα στάδια

### Προσαρμοσμένη πολιτική επανέναρξης

Παράμετροι κατασκευαστή αντικατάστασης:

```csharp
services.AddSingleton<TranslationRetryService>(
    sp => new TranslationRetryService(
        sp.GetRequiredService<ILibreTranslateService>(),
        sp.GetRequiredService<IPlaceholderService>(),
        sp.GetRequiredService<ILogger<TranslationRetryService>>(),
        stageMaxRetries: 5,        // More retries
        stageRetryDelaySeconds: 60  // Longer delays
    ));
```

### Προσαρμοσμένος χειρισμός του κατόχου του χώρου

Εφαρμογή για αλλαγή σύνταξης ή αποθήκευσης τοποθέτων:

```csharp
public class CustomPlaceholderService : IPlaceholderService
{
    // Use {{name}} syntax instead of {name}
    // Store in database instead of JSON file
    // Encrypt sensitive placeholder values
}
```

## Στρατηγική δοκιμών

### Δοκιμή μονάδας

Κάθε υπο-υπηρεσία μπορεί να ελεγχθεί ανεξάρτητα:

- Mock για την προσομοίωση επιτυχίας/αποτυχίας
- Για την επαλήθευση της υποβολής εκθέσεων
- Χρήση προσωρινών καταλόγων για το αρχείο I/ Ο
- Επαλήθευση της συμπεριφοράς εξοικονόμησης ανά γλώσσα

### Δοκιμές ολοκλήρωσης

- Πλήρης λειτουργία αγωγών με πραγματική (τοπική) LibreTranslate παράδειγμα
- Επαλήθευση μηνυμάτων SignalR παραδίδονται σε συνδεδεμένους πελάτες
- Δοκιμή ταυτόχρονης πρόληψης (semafore)
- Επικύρωση της δομής σήμανσης μετά τη μετάφραση

### Τελικές δοκιμές

- Ενεργοποίηση μετάφρασης μέσω API ή προγραμματιστή
- Επαλήθευση όλων των αρχείων γλώσσας προορισμού που δημιουργούνται/ενημερώνονται
- Έλεγχος αρχείων μεταδεδομένων που περιέχουν σωστή κατάσταση μπλοκ
- Επιβεβαιώστε ότι οι κάτοχοι του χώρου διατηρούνται σε όλες τις μεταφράσεις

## Στοιχεία επιδόσεων

- **Μνήμη**: Η εξοικονόμηση ανά γλώσσα εμποδίζει την κατοχή όλων των λεξικών στη μνήμη
- **Disk I/O**: Τα αρχεία μεταδεδομένων προσθέτουν μικρά γενικά έξοδα, αλλά ενεργοποιούν τις στοιχειώδεις εργασίες
- **Δίκτυο **: Αλληλουχική επεξεργασία με θρότλινγκ αποτρέπει συντριπτική LibreTranslate
- **CPU**: SHA-256 hashing και regex επικύρωση είναι γρήγορη σε σχέση με τη λανθάνουσα μετάφραση
- **ΣημείωσηR**: Ελαφριά μηνύματα, καμία συμπίεση ωφέλιμου φορτίου που απαιτείται για τυπικές αναφορές

## Μετανάστευση από τον μονολιθικό σχεδιασμό

Το πρωτότυπο περιείχε όλη τη λογική σε μια τάξη. Η διαδρομή της μετανάστευσης:

1. Εξαγωγή λογικής χώρας →
2. Εξαγωγή λογικής JSON →
3. Εξαγωγή λογικής Markdown →
4. Εξαγωγή έκδοσης SignalR →
5. Εξαγωγή retry λογική →
6. Απλοποίηση του ενορχηστρωτή μόνο στην αντιπροσωπεία

Όλες οι υπάρχουσες διεπαφές () παραμένουν αμετάβλητες. Οι καταναλωτές του αγωγού δεν βλέπουν αλλαγές που σπάνε.

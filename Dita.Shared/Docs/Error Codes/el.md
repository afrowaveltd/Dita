# Κωδικοί σφαλμάτων

Η Dita χρησιμοποιεί μια αρχιτεκτονική κώδικα με χωρισμένο εύρος **, ενοποιημένου σφάλματος** που παρέχει τόσο domain-specific enums όσο και έναν ενιαίο τύπο αλιευμάτων. Κάθε σφάλμα στο σύστημα —από τις αστοχίες του δικτύου έως το δίσκο I/O, από την ταυτοποίηση έως τη διαμόρφωση — αντιπροσωπεύεται από ένα μέλος αυτής της ιεραρχίας.

### Μοτίβο διπλού αίνου

Κάθε τομέας σφάλματος αντιπροσωπεύεται από ** και οι δύο ** ένα εστιασμένο υποενό (π.χ.) και καταχωρήσεις στο ενοποιημένο αίνιγμα. Τα sub-enum χρησιμοποιούν γυμνά ονόματα· το ενοποιημένο enum προθέματα ονόματα με την κατηγορία:

```csharp
// Sub-enum — domain-specific context
NetworkError.ConnectionRefused    // 1003

// Unified enum — catch-all reference
ErrorCode.NetworkConnectionRefused  // 1003 — same numeric value
```

Αυτό επιτρέπει στον κώδικα να λειτουργεί με συγκεκριμένους τύπους domain όταν το πλαίσιο είναι γνωστό, ενώ υποστηρίζει επίσης το γενικό χειρισμό σφαλμάτων που λειτουργεί σε όλους τους τομείς.

### λαντινέλη

Κάθε υποενός ορίζει ως τη βασική τιμή του εύρους του (π.χ.). Η μέθοδος το αναγνωρίζει και επιστρέφει.

## Κλάση κώδικα σφάλματος

Το enum ενοποιεί όλες τις υποενικές τιμές σε έναν ενιαίο τύπο με ** μη-επικαλυπτόμενες ** ακέραιες σειρές. Η συντροφική στατική τάξη παρέχει εξανθρωπισμό:

```csharp
// Get human-readable text for any error code
string text = ErrorCodeText.ErrorText(ErrorCode.NetworkConnectionRefused);
// → "Network connection refused"

string text2 = ErrorCodeText.ErrorText(5005);
// → "Localization invalid translation format"
```

### Λογική εξανθρωπισμού

ακολουθεί προσέγγιση ρύθμισης της σύμβασης:

1. PascalCase ονόματα χωρίζονται σε λέξεις μέσω regex
2. Γνωστά ακρωνύμια ομαλοποιούνται (Io → I/O, Api → API, Dns → DNS, Http → HTTP, Ssl → SSL, Mfa → MFA, OAuth → OAuth, Sso → SSO, Xml → XML, Json → JSON, Url → URL)
3. Διατηρούνται μάρκες για όλα τα καλύμματα (π.χ.)
4. Τιμές που λήγουν σε αντάλλαγμα

## Χρήση κωδικών σφάλματος

### Σε αναφορές αγωγών

Τα μεταφραστικά λάθη μεταφέρονται σε αρχεία:

```csharp
public class TranslationError
{
    public string Source { get; set; }        // Language code, file path, or stage name
    public ErrorCode Code { get; set; }       // Unified error code
    public string ErrorMessage { get; set; }  // Human-readable text
}
```

### Σε απαντήσεις API

```csharp
var result = Response<TranslateResult>.Fail(
    ErrorCodeText.ErrorText(ErrorCode.NetworkConnectionRefused),
    ErrorCode.NetworkConnectionRefused);
```

### Εξανθρωπισμός οποιουδήποτε κώδικα

```csharp
// From enum value
string text = ErrorCodeText.ErrorText(ErrorCode.StorageDeadlockDetected);
// → "Storage deadlock detected"

// From raw integer (validates against defined values)
string text2 = ErrorCodeText.ErrorText(2010);
// → "Storage deadlock detected"

// Undefined code
string text3 = ErrorCodeText.ErrorText(99999);
// → "Unknown error (99999)"
```

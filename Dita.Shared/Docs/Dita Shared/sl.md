# Dita. Skupni pregled

**Dita.Shared** is the cross-platform shared library that powers Dita's localization, translation, identity, and mailer subsystems. It is consumed by the Server, GUI, and TUI front-ends and contains no UI code itself — only services, models, enums, and infrastructure.

## Načela projektiranja

- ** Interface-first**: vsaka storitev ima osredotočen vmesnik (, , , itd.)
- **Rezultati objektov glede na izjeme**: vse storitvene metode se vrnejo za varno ravnanje z napakami
- **Varnost na tleh**: v, ; v
- **Inkrementalna vztrajnost**: slovarji in datoteke Markdown se shranijo na jezik takoj po prevodu
- ** Hvaležen razkroj**: manjkajoče datoteke proizvajajo prazne zbirke, ne pa izjem
- ** Prepišite na miss**: in samodejno dodajte manjkajoče tipke v privzetem slovarju za odložen prevod

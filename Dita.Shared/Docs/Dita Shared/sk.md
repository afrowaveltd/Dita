# Dita. Spoločný prehľad

**Dita.Shared** is the cross-platform shared library that powers Dita's localization, translation, identity, and mailer subsystems. It is consumed by the Server, GUI, and TUI front-ends and contains no UI code itself — only services, models, enums, and infrastructure.

## Princípy návrhu

- **Interface-first**: každá služba má cielené rozhranie (, , atď.)
- **Výsledky nad výnimkami**: všetky servisné metódy sa vrátia pre bezpečnú manipuláciu s chybami
- **Thread bezpečnosť**: in , ,; in
- **Prírastková perzistencia**: slovníky a súbory Markdown sú uložené v jednom jazyku ihneď po preklade
- **Rýchle degradácia**: chýbajúce súbory produkujú prázdne zbierky, nie výnimky
- **Napísať na slečnu**: a automaticky pridať chýbajúce kľúče do predvoleného slovníka pre odložený preklad

# Dita. Visión general

**Dita. Shared** es la biblioteca compartida multiplataforma que potencia los subsistemas de localización, traducción, identidad y correo de Dita. Es consumido por el Servidor, GUI y TUI front-ends y no contiene ningún código UI en sí — sólo servicios, modelos, enums e infraestructura.

## Principios de diseño

- **Interface-first**: cada servicio tiene una interfaz enfocada (, , , etc.)
- **Objetos de resultados sobre excepciones**: todos los métodos de servicio regresan para el manejo seguro de errores
- **Tread safety**: in , , ; in
- **Incremental persistencia**: los diccionarios y los archivos Markdown se guardan por idioma inmediatamente después de la traducción
- **Degradación graciosa**: los archivos perdidos producen colecciones vacías, no excepciones
- **Write-through on miss**: and auto-add missing keys to the default Dictionary for aferred translation

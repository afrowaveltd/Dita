# Dita. Über uns

**Dita. Geteilt** ist die plattformübergreifende gemeinsame Bibliothek, die Ditas Lokalisierung, Übersetzung, Identität und Poster-Subsysteme unterstützt. Es wird von dem Server, GUI und TUI Frontends verbraucht und enthält keinen UI-Code selbst — nur Dienste, Modelle, Enums und Infrastruktur.

## Gestaltungsprinzipien

- **Interface-first**: Jeder Service hat eine fokussierte Schnittstelle (, , usw.)
- **Result objects over exceptions**: all service methods return `Response<T>` for safe error handling
- **Gewichtssicherheit**: in
- **Incremental persistence**: dictionaries and Markdown files are saved per-language immediately after translation
- **Graceful degradation**: missing files produce empty collections, not exceptions
- **Schreiben auf miss**: und auto-add fehlende Schlüssel zum Standardwörterbuch für latente Übersetzung
